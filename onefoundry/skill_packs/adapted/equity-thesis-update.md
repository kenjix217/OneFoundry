# public equity thesis update

Use this procedure when the operator supplies a prior thesis or watchlist entry and explicitly asks for a quick text review. Do not reconstruct an unseen tracker from run metadata.

1. Preserve the prior thesis text, issuer and security identity, owner, review date, and original prove-or-kill tests. Ask for the prior entry if it is not supplied.
2. Compare each test with dated supplied evidence or public pages fetched by an admitted built-in Researcher. Label confirmed change, conflicting evidence, and still-open checks separately.
3. Draft separate company-thesis evidence status and security-thesis readiness. Label a new threshold as a proposed draft, distinct from the prior owner's rule. Without sourced price and valuation evidence, leave any stock action or investability call unresolved. Do not infer holdings, sizing, price action, consensus, or an automatic review cadence from silence.
4. Return a before/after change note with supplied document pointers or fetched page URLs as available, plus remaining uncertainty. Save a text snapshot through `write_text_artifact_v1` only when requested and admitted; leave any actual tracker update to its owner.

This procedure does not monitor markets in the background or edit an external portfolio or tracker.
