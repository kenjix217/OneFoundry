# initial private credit screen

Use this screening-grade procedure for a named borrower and proposed credit question. Work from operator-supplied financials and terms; public web can supplement public facts only through an admitted built-in Researcher and without sending private terms in queries.

1. Pin borrower entity, transaction purpose, period, currency, financial basis, facility type, and source cutoff. Separate reported EBITDA, adjustments, cash flow, liquidity, debt, and covenant EBITDA.
2. Test concentration, cyclicality, cash conversion, maturity runway, collateral, sponsor support, and downside drivers from supplied evidence. Present a newly calculated ratio only through admitted `decimal_calculate_v1` with explicit numerator, denominator, and units; otherwise name the needed calculation.
3. Identify the first cash, covenant, customer, or maturity breakpoint only when governing definitions and source values are present. Otherwise name the precise document or schedule needed.
4. Return a diligence-stage view, top risks, conditions to continue, and what prevents committee reliance. Save Markdown only when `write_text_artifact_v1` is requested and admitted.

This is not an underwritten debt-capacity model, credit approval, legal covenant opinion, or lender commitment.
