# Operator board operations map

**Trigger:** An operator asks how an external board flow translates to OneFoundry’s single-operator setup.

**Required inputs:** Desired project, profiles, first work order, approval boundaries, and observed OneFoundry configuration.

**Capability preflight:** External company creation, CEO hire, and board API are absent. OneFoundry project/profile and approval UI remain operator-owned; role tools cannot hire or launch.

**Procedure:** Map each requested board step to project creation, profile definition, work-order draft, approval review, and run/QA evidence. Name the actual operator action and required readback for each.

**Output:** Return an ordered setup map with unsupported external steps flagged. Do not claim a company or agent was created.
