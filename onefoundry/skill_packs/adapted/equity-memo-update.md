# public equity memo update

Use this procedure for an explicitly short public-equity memo or update from supplied prior analysis and source evidence. The operator must provide the prior memo text when preserving or revising it matters; OneFoundry cannot read an arbitrary saved document through live text tools.

1. State the issuer, security, audience, prior memo date, current evidence cutoff, and decision question. Separate prior claims from new evidence and user-supplied estimates.
2. Lead with the supported change in view or decision ask. Tie each material statement to a supplied source or, for an admitted built-in Researcher, a fetched public filing or company disclosure.
3. Cover thesis evidence, valuation or scenario inputs only when sourced, key risk and countercase, near-term catalysts, and what would change the view. Mark missing market price, consensus, holdings, or execution data as gaps.
4. Return a concise internal draft or marked revision. Save Markdown through `write_text_artifact_v1` only when requested and admitted; request separate review before external circulation.

This is a text memo update, not the source pack's formal DOCX or HTML investment committee artifact or an executable trade call.
