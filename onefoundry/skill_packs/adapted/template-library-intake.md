# template library intake

Use when an operator wants a reusable artifact template from an exact reference. Inputs: reference identity and rights, desired template kind, audience, reuse rules, and target OneFoundry project.

1. Record the source and the aspects to retain: structure, formulas, visual system, or voice.
2. Specify preview, version, ownership, and review requirements for a future template package.
3. Identify the exact Skill Library binding and artifact capabilities needed for reuse.

Capability preflight: Require authorized reference access, relevant native renderer, preview capture, and an OneFoundry template packaging/import path. External personal-skill tooling and Google Drive export are not OneFoundry role tools.

Output: Return an intake specification and blocker; do not claim an external personal skill or native template was created. Save a requested Markdown brief only when `write_text_artifact_v1` is admitted.
