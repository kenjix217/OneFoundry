# market sizing

Use this procedure when a work order supplies a market definition and quantitative inputs or asks for an assumption-driven scenario.

1. Define the buyer, geography, time horizon, unit being counted, and what is inside the market. Separate total opportunity from reachable customers.
2. List every supplied input with its source and date. Mark an unsourced number as an assumption, never as a verified fact.
3. Build a transparent calculation from units, eligible share, adoption, and value per unit as appropriate. Show units and arithmetic so the estimate can be checked.
4. Vary the assumptions that drive the result and show a low, central, and high scenario. Explain which unknown input changes the decision most.
5. Return the model, source and assumption table, range, and next validation step. If the supplied inputs cannot support a number, return a model template with missing inputs instead of inventing a market size.

An admitted built-in Researcher may search and fetch public HTTPS sources for current inputs when configured. OneFoundry has no connected market-data feed through this procedure; cite fetched public data with its as-of date and do not claim a live quote or licensed dataset.
