# chart choice and critique

Use this procedure when a work order asks which chart fits a stated decision or asks for a critique of a supplied chart description. Inputs are the audience, question, data fields and units, a written description or data excerpt, and any known source limits.

1. Identify the comparison or relationship the viewer must understand. Separate supplied facts from missing data and visual details.
2. Recommend one chart form and explain the encoding, scale, labels, and reading order. Name a simpler alternative when it would serve the decision as well.
3. For a critique, tie each finding to a supplied value, label, design description, or admitted evidence. Check misleading baselines, aggregation, missingness, color dependence, and mobile readability.
4. Give the smallest actionable revision and the data or visual inspection needed to validate it.

Return a short recommendation or prioritized critique with evidence and open checks. This is a text assessment; do not claim to have seen pixels, rendered a chart, or passed browser QA unless those results were actually supplied by an admitted path. Save Markdown only when `write_text_artifact_v1` is admitted and requested.
