# Skill Library candidate review

**Trigger:** An operator proposes a reusable procedure for the project Skill Library.

**Required inputs:** Intended trigger, sample work order, required evidence, tool needs, and any existing similar skill.

**Capability preflight:** Skill text does not grant tools. The operator owns Skill Library creation and exact profile binding; a role may draft text only.

**Procedure:** Search supplied library names for overlap, choose a focused procedure, give two worked input/output examples, and check source terms before any direct reuse. State unavailable tool needs and a failure path.

**Output:** Return an original candidate procedure and operator setup checklist, not an installed skill or catalog import.
