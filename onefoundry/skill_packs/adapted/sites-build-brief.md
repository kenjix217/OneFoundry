# site build brief

Use when an operator wants to scope a website, portal, or dashboard for a Sites project. Inputs: user goal, audience, pages, content sources, interactions, brand assets, hosting target, and approval constraints.

1. Define the page map, primary flows, content and asset ledger, and mobile behavior.
2. Describe the data and permission boundaries for every interactive element.
3. Write acceptance checks for navigation, content accuracy, accessibility, and responsive layouts.

Capability preflight: Require a Sites project/runtime and approved build and browser-QA path to implement or preview. OneFoundry has no Sites builder or image-generation role tool.

Output: Return a build-ready specification and missing assets/capabilities; do not claim a site or preview was created. Save a requested Markdown brief only when `write_text_artifact_v1` is admitted.
