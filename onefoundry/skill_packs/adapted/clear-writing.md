# clear writing

Use this procedure when a work order supplies a draft that needs clearer wording. Work only with the text and audience supplied in the order or approved memory.

1. Identify the reader, purpose, and facts that must survive the rewrite. Keep names, dates, quantities, legal terms, and uncertainty exactly supported by the source.
2. Use familiar words, active verbs, short sentences, and one instruction per step. Define a necessary technical term at first use. Keep one topic per paragraph.
3. Preserve links, citations, approval conditions, and next actions. Flag a sentence whose meaning is unclear instead of choosing an interpretation silently.
4. Return the revised text and a short list of material ambiguities or claims that still need checking. Do not present this as certified Simplified Technical English; no controlled dictionary is available in OneFoundry.

This procedure does not send or publish. Save a text draft with `write_text_artifact_v1` only when the work order requests it and saved and current tool permission admits the action; report the returned artifact record.
