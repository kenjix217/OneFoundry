# content work review

Use this operator-started procedure to choose the next content drafts and expose publication blockers. The operator supplies the campaign goal, current calendar or draft list, approved claims, channels, and any launch dates.

1. Set a cutoff and check each proposed item against audience, purpose, source evidence, and current approval state. Use admitted project context reads for named work; do not infer a complete calendar from a bounded recent-work list.
2. Recommend up to three next drafts, each with a working title, channel, owner, needed source or asset, and review criterion. Explain why each serves a different purpose.
3. List blocked publication separately: missing fact check, asset, legal or operator approval, or unknown delivery state. Do not turn a draft into a claim that a post was sent.
4. Return the shortlist and exact operator decisions. Use `write_text_artifact_v1` for an approved Markdown note or `create_draft_work_order_v1` for a same-project draft only when admitted and requested.

No schedule trigger, publisher, social connector, or outbound approval is created by this procedure. A content calendar draft can be prepared with the existing dedicated procedure.
