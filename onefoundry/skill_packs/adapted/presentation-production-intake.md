# presentation production intake

Use when a work order asks to read, edit, or create a slide deck. Inputs: audience, message, exact deck or reference, slide constraints, figures, and editable-content needs.

1. Map one idea and its evidence to each proposed slide.
2. List native element, citation, layout, and accessibility requirements.
3. Plan slide rendering and visual review, including overflow and source fidelity.

Capability preflight: Require an admitted PPTX or connected Slides tool, artifact storage, renderer, and slide-image QA. OneFoundry text roles have none of these.

Output: Return a slide outline and production checklist or blocked result; do not claim a deck exists. Save a requested Markdown brief only when `write_text_artifact_v1` is admitted.
