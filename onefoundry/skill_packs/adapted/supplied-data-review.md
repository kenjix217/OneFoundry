# supplied-data review

Use this procedure to evaluate a table excerpt, calculation, or data description supplied in a work order. State the evidence boundary before drawing a conclusion.

1. Identify the intended use, time window, grain, source description, expected keys, and supplied sample size. A sample cannot prove the quality of an unseen full dataset.
2. Check only what the supplied material permits: missing fields, apparent duplicates, inconsistent units or dates, calculation steps, and conflicting totals. Recompute simple arithmetic when the inputs are present.
3. Distinguish a demonstrated defect from a plausible risk and an untested check. Explain how each could affect the intended decision.
4. Give the exact query, source read, or owner check needed to validate a suspected issue. Do not invent a database result or freshness timestamp.
5. Return findings with evidence, severity, confidence, and remaining checks. If no data was supplied, return a focused review plan rather than a quality verdict.

This procedure does not connect to a database, spreadsheet, or analytics service.
