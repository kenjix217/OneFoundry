# Page publication plan

**Trigger:** An operator wants a page drafted or an existing page updated.

**Required inputs:** Audience, page purpose, approved copy, destination, revision, and review requirements.

**Capability preflight:** `write_text_artifact_v1` can save Markdown text when admitted. OneFoundry has no page host, revisioned page API, or publisher; outbound publication needs approval.

**Procedure:** Outline sections, source every claim, identify links/assets and accessibility needs, and specify a reviewable draft. If replacing a page, note the current revision needed to prevent overwrite.

**Output:** Return a Markdown draft or content plan and publication checklist; mark publishing blocked.
