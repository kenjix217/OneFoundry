# banking quick comps review

Use this narrow report-mode screen for a named transaction target or issuer with a supplied peer set and dated valuation inputs. It can compare peer rationale and implied values without creating an editable workbook. Do not disclose confidential transaction facts through public search.

1. Set transaction context, subject entity, valuation date, currency, fiscal basis, and metric definition. Separate trading peers from precedent transactions and explain inclusions or exclusions.
2. Record every equity value, enterprise-value bridge, EBITDA, revenue, forecast, or transaction consideration with source and as-of date. Do not mix stale trading prices with current denominators or treat missing debt as zero.
3. Calculate bounded multiples or implied ranges only through admitted `decimal_calculate_v1`; show inputs and reconcile units. Without calculation admission, list the required calculation instead of presenting a new numeric multiple. Treat synergies, control premium, outliers, and capital structure as separate assumptions or gaps.
4. Return a quick valuation read, peer caveats, and missing evidence that would change a banker decision. Save Markdown or CSV through `write_text_artifact_v1` only when requested and admitted.

This is not a signed valuation, fairness opinion, refreshed market-data feed, or formula-checked comps workbook.
