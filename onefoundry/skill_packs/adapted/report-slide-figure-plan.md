# report and slide figure plan

Use this procedure when a work order needs to plan figures for a report or presentation from supplied findings. Inputs are the audience, message, source facts, target medium, page or slide budget, and available figure data.

1. Assign one purpose to each proposed figure and connect it to a supported claim. Record units, source date, and any caveat that must travel with the figure.
2. Outline the figure order, captions, page or slide placement, and a text alternative. Identify reusable data and the inputs needed to regenerate each figure.
3. Specify review checks for consistency of numbers, legibility, attribution, overflow, and export quality.
4. Separate content ready for drafting from missing data, approvals, and required rendering checks.

Return a text figure inventory and layout brief. OneFoundry can save requested Markdown via admitted `write_text_artifact_v1`; it cannot create or visually verify PDF, DOCX, PPTX, charts, or slides through this procedure.
