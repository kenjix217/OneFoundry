# KPI design

Use this procedure to propose measures for a decision or operating goal stated in the work order. Use only supplied facts and approved memory.

1. State the decision, audience, outcome, time window, and unit of analysis. Ask for the missing goal when a metric would otherwise be arbitrary.
2. Propose a small set of outcome and driver measures. For each, define numerator, denominator, exclusions, grain, owner, source, update cadence, and the decision it informs.
3. Add a guardrail when a measure could improve by harming quality, privacy, or another goal. Identify instrumentation or source gaps without claiming they are solved.
4. Set a numerical target only when a trustworthy baseline and time horizon are supplied. Otherwise label a target as provisional and state what baseline is needed.
5. Return a metric table, calculation examples when inputs allow, and a validation plan. Do not claim a warehouse, dashboard, or live metric was inspected.
