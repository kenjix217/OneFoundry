# Identity capsule review

**Trigger:** A team proposes small visual identity or status capsules for an OneFoundry surface.

**Required inputs:** Brand rules, target surface, available visual assets, status semantics, and accessibility requirements.

**Capability preflight:** OneFoundry has no image generation or screenshot inspection on the live role path. Static fixture inspection is separate, approval-bound, and text-only. External capsule assets are not OneFoundry assets.

**Procedure:** Choose the appropriate surface and define distinct color, shape, label, fallback, contrast, and motion rules from the supplied brand. Identify where status must be carried by text rather than color alone.

**Output:** Return a visual specification and human browser checks; mark actual art generation and UI verification unexecuted.
