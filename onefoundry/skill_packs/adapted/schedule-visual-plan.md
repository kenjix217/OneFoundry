# schedule visual plan

Use this procedure to decide whether supplied project timing belongs in a Gantt chart, milestone timeline, calendar, Kanban view, or table. Inputs are task IDs, names, dates, dependencies, baselines, status, source, intended decisions, and known missing fields.

1. Classify each time field as planned, actual, estimated, or unknown. Do not infer dates from status or prose.
2. Choose the view that makes the operator's scheduling decision easiest. For a Gantt recommendation, define rows, spans, milestones, dependencies, baseline display, and the treatment of unscheduled tasks.
3. Describe the minimum interactions, edit validation, conflict handling, stale-data cue, and mobile summary needed if the view will be interactive.
4. List source mapping questions and a focused acceptance checklist.

Return a written view decision and field-to-visual specification. This procedure does not import scheduling files, synchronize a project tool, render a timeline, or verify browser behavior. Save Markdown only through admitted `write_text_artifact_v1` when requested.
