# public equity shock brief

Use this quick Researcher procedure for a named public event or policy change and its possible effect on listed issuers. Search and fetch public HTTPS evidence only through admitted Researcher web tools; otherwise use supplied sources.

1. Pin the event, status, date, source cutoff, prior baseline, and what is actually new. Distinguish an official action from a proposal, report, or market rumor.
2. Trace one or more concrete transmission paths from the event to issuer revenue, costs, balance sheet, estimates, or valuation. Separate direct effects from higher-order effects and identify the first variable that would confirm each path.
3. Name the most exposed listed issuers or sectors only when evidence supports their exposure. Do not infer what is priced in without timestamped price, estimate, or valuation evidence; label that question open.
4. Return a brief event status, exposure map, strongest counterargument, conditional scenarios, and monitoring signals. Cite each supplied source by its available owner or document pointer and date, and include URLs for fetched web pages; save Markdown only when `write_text_artifact_v1` is requested and admitted.

Without portfolio holdings or a live market-data source, this is a research queue, not an add, trim, hedge, or trade recommendation.
