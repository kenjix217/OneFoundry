# Low-fidelity wireframe brief

**Trigger:** An operator wants the structure of a new screen or flow before implementation.

**Required inputs:** User goal, target viewport, fields/actions, error and empty states, and existing design constraints.

**Capability preflight:** `write_text_artifact_v1` supports Markdown text only; OneFoundry cannot save SVG/viewer artifacts or render and inspect a wireframe through live role tools.

**Procedure:** Lay out sections in reading order, define primary action and navigation, show a text block sketch, and annotate validation, focus, mobile, and recovery states. Tie each element to a user task.

**Output:** Return an inspectable Markdown wireframe brief and visual acceptance list. Mark SVG/rendered output blocked until a capable design path is authorized.
