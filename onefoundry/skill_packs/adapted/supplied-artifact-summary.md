# supplied artifact summary

Use this procedure when the operator supplies the exact text or reviewed excerpt of an analysis artifact and asks for a short, copyable internal summary. A saved artifact's metadata is not its contents; request the content when it is absent.

1. Identify the artifact title, owner, version, source cutoff, intended reader, and decision it informs. Treat an excerpt as partial and preserve its limits.
2. Extract the answer, two or three supporting facts with their source pointers, material caveats, and the next action only if the artifact supports one. Keep reported facts separate from interpretation.
3. Check every number, date, and link against the supplied content. Do not claim a chart, dashboard view, underlying row, or source was inspected unless that exact evidence was supplied or returned by an admitted tool.
4. Return copyable text with an artifact reference supplied by the operator. Save it through `write_text_artifact_v1` only when requested and admitted; report the returned record.

This procedure does not publish, email, message, grant access to, or create a public link for an artifact.
