# supplied analysis review

Use this procedure to review an analysis excerpt, table, or written conclusion supplied with a work order. State the reviewed material and intended decision before judging readiness.

1. Identify the main claims, source descriptions, definitions, periods, units, and calculations visible in the supplied material. Note which underlying records are unavailable.
2. Recompute consequential arithmetic from visible inputs, using `decimal_calculate_v1` when admitted. Check denominator, units, comparable periods, missing versus zero values, and consistency between a stated number and its conclusion.
3. Assess whether the evidence supports each central claim. Separate demonstrated errors from plausible risks and checks that cannot be performed with the supplied excerpt. Treat causal language, extrapolation, and selected samples with appropriate caution.
4. Give a concrete correction or owner check for each material issue. Do not silently alter the source analysis or claim that an unavailable dataset, chart, or rendered report was verified.
5. Return a scoped verdict: ready within reviewed material, usable with named caveats, or needs revision. Include the exact evidence checked and the remaining source or visual checks.

This is a review of supplied text and tables. It does not perform a deep data audit, database reconciliation, dashboard rendering, or source-system repair.
