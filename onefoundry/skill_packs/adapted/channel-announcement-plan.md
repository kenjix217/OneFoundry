# Channel-specific release message

**Trigger:** An operator requests a community-channel message tied to a release.

**Required inputs:** Approved changelog, actual release availability, audience, channel rules, approved roadmap, contributor credits, and links.

**Capability preflight:** Text drafting and `write_text_artifact_v1` may be admitted. OneFoundry has no Discord publisher; sending needs explicit approval and a selected connector.

**Procedure:** Choose a few verified highlights, separate shipped facts from future work, preserve approved voice without impersonating a person, and cross-check version, links, and credits against the changelog.

**Output:** Return copy-ready proposed text and fact checklist. Mark posting blocked; do not fabricate community news or ping an audience.
