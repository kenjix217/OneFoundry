# public catalyst brief

Use this text procedure only for an explicitly requested quick brief on one named public-company event or a small named watchlist. A Researcher may use admitted `public_web_search_v1` and `public_page_fetch_v1` for public HTTPS evidence. It does not create a recurring calendar, workbook, market forecast, or trading instruction.

1. Define the issuer, event, requested time window, and decision the event could affect. Search for an official issuer, regulator, or exchange date before using an aggregator.
2. Record the event source URL, publication date when available, fetch time, and whether timing is confirmed, a range, an estimate, or unknown. Preserve conflicting dates; do not turn a soft window into an exact day.
3. Explain what evidence the event could produce, which stated assumption it would test, and what preparation is useful. Separate observed facts from scenario implications and avoid unsupported probability or price estimates.
4. Return a compact event row or brief with timing confidence, source, evidence to watch, preparation, and possible decision implications. State gaps and a source cutoff. A later change requires a new source check, not a silent update.

Use `decimal_calculate_v1` only for explicitly supplied arithmetic, and label calculated values with their input assumptions. Save a Markdown or CSV artifact through `write_text_artifact_v1` only when admitted and requested. No tool here schedules refreshes or creates a calendar event.
