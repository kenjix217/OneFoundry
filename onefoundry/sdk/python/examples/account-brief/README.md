# Account brief reference package

This package contains synthetic data only. The Python transform is pure; the API, MCP, and outbound webhook slots have no endpoint or credential in the package. Importing and activating the exact package does not grant a profile a tool or enable a connection. Bind and enable each slot in the Tool Gateway, grant the canonical tool IDs to a profile, and approve each connected call. Delivery requires a separate exact write approval. Create an inbound Gateway webhook subscription and a `webhook.received` rule for `account.created` to produce a draft work order; incoming webhooks are not package-executed hooks.

From the application directory (`onefoundry/`), run `uv run --locked onefoundry-sdk validate sdk/python/examples/account-brief`, `uv run --locked onefoundry-sdk test sdk/python/examples/account-brief`, then `uv run --locked onefoundry-sdk build sdk/python/examples/account-brief --output /tmp/onefoundry-account-brief.zip`. These commands use the application's lockfile and editable SDK dependency. The SDK test validates fixture structure. The joined Gateway integration test checks execution against disposable PostgreSQL, local fixture endpoints, and an isolated Docker worker.
